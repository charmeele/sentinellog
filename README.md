# 🛡️ SentinelLog: Basic Log Security Analyzer

SentinelLog — это легковесный инструмент на Python для анализа веб-логов сервера. Он ищет признаки распространенных кибератак, используя набор сигнатур (паттернов), что позволяет администратору быстро выявить попытки взлома.

## 🚀 Функционал
- **Обнаружение SQL-инъекций:** Поиск попыток манипуляции базой данных.
- **Поиск XSS-атак:** Выявление внедрения вредоносных скриптов в запросы.
- **Path Traversal:** Обнаружение попыток чтения системных файлов (например, `/etc/passwd`).
- **Brute Force Detection:** Поиск частых ошибок авторизации (401 Unauthorized).

## 🛠 Технологии
- **Язык:** Python 3.x
- **Библиотеки:** `re` (регулярные выражения), `os` (работа с файловой системой).

## 📦 Установка и запуск
1. Клонируйте репозиторий:
```bash
   git clone https://github.com/charmeele/sentinellog.git
   cd sentinellog
```
2. Запустите анализатор:
```bash
   python main.py
```

## 📝 Пример работы
Программа сканирует файл `access.log` и выводит результат в следующем формате:
`Строка 1 | Тип: SQL Injection`
`Данные: 127.0.0.1 - - [01/May/2026] "GET /index.php?id=1' OR '1'='1" 200`
